# ComfyUI 工作流作者开发包·开发者预览版

安装发行0.6.1030；SDK合同2.0.0。安装包包含公开源码、固定CLI/worker、schema、模板和12套作者包。此版本面向愿意由编程智能体或开发者接入自有工作流的用户；不是任意工作流自动转换器，也不是全SDK正式就绪声明。

## 开始使用

从安装目录 `user-examples/comfy-workflow-authoring-v2/README.zh-CN.md` 和 `GENERATION-EXAMPLES.zh-CN.md` 选择接近目标的完整样例，将整个目录复制到可写位置，再交给智能体其中的 `AGENT-TASK.zh-CN.md`、用户已跑通的真实工作流、节点定义、依赖名称、输入素材和输出要求。无需主仓源码、内部报告或开发者机器路径。

作者使用Rust1.95.0、wasm32-wasip2目标、Windows MSVC工具链及PowerShell7。工具链、模型、节点、FFmpeg/ffprobe不包含在作者包中；首次构建需显式联网取得锁定依赖，之后缓存齐备才可离线编译。不得删除用户已有Cargo配置绕过检查，改用无隐式配置的独立作者目录。

完成build/check/pack后，在「设置 → 第三方适配器 → 安装适配包」选择生成的build/install目录。需要配置时展开「高级安装选项」，填写样例生成的完整host-config.app.json；不能用只有endpoint的两字段配置代替。随后在工作流详情关联正确原件摘要、包身份/版本和操作，并到对应工作台实际提交。包卡片双击可改显示别名、手柄可拖动排序；别名不改变包身份或任务续办身份。

## 已证明的范围

P01—P13在各步固定基线上完成代表性文生图、图生图、有序多参考图、单任务多图输出、文生视频、图生视频、图文音多参视频及视频编辑的作者/软件链路。部分阶段验证关闭面板回收和正常退出后沿原任务续办；细节以各样例README为准，不将P13重新提交成功称为旧任务续办。

P12/13由独立作者接入，但得到过诊断提示。另有0.6.1028新Z-Image真实工作流零外部技术提示验收：独立作者仅靠安装资料与目标材料完成编译、安装关联、真实出图、回收与原图另存；未验该目标重启续办或新视频盲验，该新作者包未收入这12套样例。

本次SDK侧只更新资料/状态并随主程序重包安装版；已有GPU成果按原输入和固定SDK复用，不声明在0.6.1030重新跑过全部模型。每个新用户工作流仍须验独立构建、软件安装关联、真实生成、回收；需要续办时还应验正常退出重开及原远端ID保持，不自动重提未知受理任务。

## 输入与环境边界

- 仅对已支持的媒体与交互原语承诺独立接入；SDK能表达schema不代表产品表单支持任意根字段、任意数量或嵌套结构。自定义标量按所选宿主的advanced闭集、类型和默认值规则声明；缺口显式报告，不改SDK/宿主或补造参数求通过。
- 当前视频生成已验自由画布入口；其它宿主/业务槽、跨平台、干净Windows虚拟机和任意未知工作流没有因此获得验收结论。
- 音频消费者当前使用WAV、每份不超过16MiB；各样例另有限定数量、时长、尺寸、帧数与用途。soundtrack_copy与voice_timbre不同，不能自动更换用途、裁剪或循环；模型/节点需在目标服务就绪。
- 已验主要为显式配置的局域网服务。任意鉴权方式、远端部署、所有错误/取消/并发矩阵和任意多输出组合未全量验收。需要凭据时走公开受管凭据合同，密钥不能写入源码或共享包。
- CLI成功、软件成功、实际安装版成功和全SDK治理通过分别记录。RELEASE-STATUS.json的顶层旧候选字段只描述独立完整SDK治理；developerPreview描述当前有限交付。G00—G06未完成，sdkReady仍为false，不能宣传为完整正式版。
